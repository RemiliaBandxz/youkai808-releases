# Youkai808 downloads

Experimental 808 destroyer by **YoukaiDigital Inc.** (Skarlet Bandxz) - [SoundCloud](https://soundcloud.com/skarletbandxz)

Every version is in [`releases/`](releases): `-Installer.zip` = Windows, `-Mac.zip` = macOS.
The newest is listed first in [`versions.json`](versions.json), which the plugin's VERSIONS button reads.

## YoukaiDigital Hub

One app for every YoukaiDigital plugin: install, update, roll back, uninstall, and activate license keys.

- Windows: [YoukaiDigitalHub-v1.0-Windows.zip](hub/YoukaiDigitalHub-v1.0-Windows.zip)
- Mac: [YoukaiDigitalHub-v1.0-Mac.zip](hub/YoukaiDigitalHub-v1.0-Mac.zip)

The product list is `hub.json`. To add a new plugin later, add an entry there with its own versions file.
